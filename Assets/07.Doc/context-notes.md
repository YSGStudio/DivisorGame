# Context Notes: 초등학교 5학년 대상 약수 카드게임 (유니티 웹/WebGL)

## 코드베이스 현황

- 해당 없음 — 새로 시작하는 유니티 프로젝트이며, 참고할 기존 코드베이스가
  없다. `implement` 단계에서 새 Unity 프로젝트(2022 LTS 이상)를 생성하는
  것부터 시작한다.

## 확정된 게임 규칙 (사용자 확인 완료)

- 목표 숫자 카드를 클리어하려면 그 수의 약수를 **전부** 제출해야 한다
  (약수 1개만 제출해서는 클리어되지 않음).
- 목표 숫자 카드는 **동시에 여러 장(기본 4장)** 이 보드에 노출되고,
  플레이어가 원하는 순서로 처리한다.
- 게임은 **스코어 어택형**이다: 제한시간이나 목표 달성 종료 조건이 없고,
  플레이어가 직접 종료 버튼을 눌러야 끝난다.

## 잠정 기본값 (PRD의 Risks And Open Decisions 참고)

- 카드 제출 조작: 드래그 앤 드롭이 아니라 "손패 카드 선택 → 목표 카드
  클릭" 방식으로 잠정 채택. 사용자가 드래그 앤 드롭을 원하면 T5를
  재설계해야 한다.
- 점수 공식 상수(기본점수 10×약수개수, 초당감점 2, 최소점수
  5×약수개수)는 잠정값이며 Inspector 노출 값으로 구현해 추후 조정
  가능하게 한다.
- 최고 점수 영구 저장은 이번 범위에 없다(세션 내 점수만).

## 기술 스택 관련 참고

- 이 PRD는 스킬의 기본 스택(React + Next.js)을 따르지 않는다. 사용자가
  명시적으로 유니티(Unity) + 웹(WebGL)을 요청했기 때문이다.
- 데이터베이스/백엔드 없음. 모든 상태는 런타임 메모리에서 관리한다.
